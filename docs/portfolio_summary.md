# 포트폴리오 요약 — MuJoCo 팔레트 적재 시뮬레이션: 단일 상자 Pick & Place

## 한 줄 소개

MuJoCo에서 Franka Panda 로봇팔이 상자를 접촉·마찰만으로 집어 2×2 팔레트의 빈 구역에 내려놓는 과정을 구현하고, 단계마다 수치로 검증한 개인 시뮬레이션 프로젝트 (실제 로봇 실험 아님)

## 사용 기술

- Python 3.13, MuJoCo 3.15 (Python 바인딩, Viewer, 오프스크린 렌더링, `MjSpec`), NumPy
- 로봇 모델: MuJoCo Menagerie Franka Panda (Apache-2.0)
- Windows, PowerShell, VS Code, Git
- 코드 작성·디버깅에 AI 코딩 도구(Claude Code) 활용

## 직접 구현한 주요 기능

- 손끝(TCP) 기준 자코비안을 이용한 Damped Least Squares IK, 위치(3D)와 위치+방향(6D) 두 가지
- 중력 보상과 속도 피드포워드를 더한 관절 위치 제어
- 직선 경로를 5 mm 간격으로 나눠 IK로 푸는 경로 계획과 경로 전체의 충돌·최소 거리 검사
- 접촉력과 마찰만으로 상자를 잡고 들기 (손에 고정하는 구속 없음)
- 손에 든 상자의 실제 크기·자세까지 포함한 운반 경로 충돌 검사
- 상자-팔레트 접촉을 감지하면 멈추는 하강, 접촉 확인 후 그리퍼 개방, 수직 후퇴
- 작업 단계별 접촉 판정 (정상 접촉과 위험 접촉 구분), 위험 시 계획 단계 거부 또는 실행 중 정지
- 파일 저장 시 시뮬레이션을 다시 실행하는 개발용 실행기

## 문제 해결 경험

- IK 결과대로 움직였는데 손끝이 6~8 mm 처지는 원인을 위치 서보 + 중력으로 찾고, 중력 보상으로 0.01~0.09 mm까지 줄임
- 위치만 맞추는 IK에서 손이 기울어 충돌하는 문제를 6D IK로 해결하고, 팔 길이 한계를 확인해 팔레트 배치를 조정함
- 3초 판정은 통과했지만 30초 시험에서 상자가 미끄러져 떨어지는 것을 발견. 마찰을 올리면 오히려 악화되는 것을 확인하고 `noslip` 설정으로 해결, 그 한계도 기록함
- 경로 계획에서 손에 든 상자를 빼고 검사하던 문제를 고치고, 위험한 경로를 실제로 거부하는지 시험으로 확인함
- 8 GB RAM 환경에서 Viewer 시작 실패를 메모리 관리로 해결함

## 검증 결과 (시뮬레이션)

- 6D IK: 32개 목표(4구역 × 4층 × 대기·놓기) 모두 통과, 자세 오차 최대 0.092 mm / 0.023°
- Pick & Lift: 100 g 상자 9.98 cm 상승, 30초 유지 중 손 안 이동 0.04 mm
- Pick & Transport: 이웃 구역이 가득 찬 조건에서도 최소 여유 32.6 mm 이상 확보
- Pick & Place: 빈 팔레트 Z1~Z4 모두 성공, 중심 수평 오차 0.09~0.60 mm, 놓은 뒤 3초 동안 움직임 없음
- 실패·거부 사례: 앞줄이 4층일 때 뒷줄 놓기는 여유 6.0 / 8.7 mm로 거부, 0.2 kg 이상 상자는 그리퍼 힘 부족으로 미끄러짐

## 한계 및 향후 계획

- 현재는 빈 구역에 상자 1개 놓기까지. 다층·연속 적재는 미구현
- 적재 높이는 시뮬레이션 정답으로 측정. 카메라 기반 측정(깊이 카메라, SAM 등)은 미구현
- 작업시간 측정과 기존 방식 비교는 아직 하지 않음
- 그리퍼 모델의 조이는 힘이 약해 약 100 g 상자까지 안정적
- 다음 계획: 다층 적재, 뒷줄 접근 여유 확보, 카메라 높이 측정, 적재 위치 규칙과 작업시간 비교
